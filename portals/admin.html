Portal controls

Configuration

Review the publishing and workflow controls required before making the administrator portal available to ministry staff.

1. Protect the page

Use GoHighLevel membership access.

Publish the administrator portal in a distinct, private page path. Associate it only with an administrator offer or membership entitlement. Keep its URL out of public and client navigation.

Recommended: /ministry-admin

2. Connect the webhook

Configure one administrative workflow endpoint.

In the script below, set GHL_ADMIN_CONFIG.adminWebhookUrl to a GoHighLevel Workflow Incoming Webhook URL. The action property enables workflow branching.

announcement.create · event.create · resource.create · prayer.status.update

Action payload

Every management form sends the action type, form data, an ISO submission timestamp, and this portal’s source label.
